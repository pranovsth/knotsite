# Knot Site

A responsive, portfolio-only React recreation of the Knot homepage design.

## Run locally

```sh
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if script execution is disabled.

The homepage keeps its GSAP scroll reveals, CSS hover states, responsive navigation, and reduced-motion support. Its account, claim, template, and footer controls are intentionally inert presentation elements.
